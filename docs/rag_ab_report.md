> 实验日期：2026-10-12 · 检索：BAAI/bge-small-zh-v1.5 向量粗排 top20 + BAAI/bge-reranker-base 精排 top5（语料 202113 篇）· 生成模型：glm-4-flash（temperature 0.6）
> 方法：对照实验，RAG 组注入检索上下文（诗人小传 + 两级检索相似诗篇）并施加引用硬约束（仅允许引用检索列表中的诗篇、《》内只填诗题），BASE 组无检索上下文；两个回答匿名乱序后由 glm-4-flash 盲评打分（1-10），评分维度：典故可信 / 意象关联 / 信息丰富 / 整体质量。
> 分组：**随机组**（任意有小传的诗）考察普遍效果；**冷门诗人组**（小传 <100 字的长尾诗人）考察模型知识薄弱区检索的增益。

## 二·附、幻觉治理闭环迭代记录

> 本节记录"发现问题 → 修复 → 数据验证"的完整工程闭环。三轮实验使用同一随机种子（样本完全一致），唯一变量为引用约束策略与判定器版本。

| 轮次 | 措施 | RAG 组幻觉率 | 关键发现 |
| --- | --- | --- | --- |
| 第 1 轮 | 仅要求"以《诗题》标注引用来源" | **12.5%**（2/16） | 模型在"必须引用"的指令压力下杜撰《庐山谣》《赠王典史五首 其五》等不存在的篇名——prompt 双刃剑效应 |
| 第 2 轮 | 加引用硬约束（仅允许引用检索列表） | **30.8%**（8/26） | 归因率升至 62%，但暴露**判定器缺陷**：5 例为诗句入《》的格式问题、2 例为库内标题排版空格未归一（《缘识 其一六》vs《缘识  其一六》）、1 例为《书名号》占位文字泄漏 |
| 第 3 轮 | prompt 补"《》内只填诗题"约束 + 判定器去空白归一化、格式违规单列 | **0.0%**（0/32） | 幻觉与格式违规双清零，93.8% 引用命中检索结果 |

**结论**：幻觉治理不是一次 prompt 修改，而是"约束 prompt → 修正度量 → 再验证"的迭代过程；第 2 轮的指标"恶化"恰恰是度量精度提升的证据。
