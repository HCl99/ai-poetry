> 实验日期：2026-10-25 · 任务：冷门诗人知识问答（介绍诗人 + 举出诗作标题与原文）· 样本：20 位冷门诗人（小传 <100 字、库内存诗 4~300 首，模型知识薄弱区）· 生成模型：glm-4-flash（temperature 0.6）
> 方法：RAG 组注入诗人小传 + 库内该诗人真实诗篇 top5（结构化检索）；BASE 组无上下文。篇名归属按 (去空白诗题, 作者) 对在全库 272475 个诗题中核验；诗句可验证率 = 回答中纯中文诗句片段（4~12 字）命中该诗人库内诗句的比例。二者均为**客观指标**，不依赖盲评；盲评四维打分与 rag_ab_test.py 同口径作为主观对照。
